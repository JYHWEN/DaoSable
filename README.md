# DaoSable

DaoSable is a distributed, multi-tenant platform that utilizes auto-scaling real-time processing to optimize data workflows via AI manager.

With DaoSable, you get a lightweight tool that stays out of your way.

**What you get**

- DaoSable is a distributed, multi-tenant
- platform that utilizes auto-scaling real-time
- processing to optimize data workflows

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoSable.git`
2. `cd DaoSable`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoSable, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
